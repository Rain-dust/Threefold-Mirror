# Past · Historical Self Reconstruction

Input: a real question, time range, private Memory and optional authorized Evidence Sources.

1. Retrieve authorized evidence and primary Fragment/Event/Outcome records. Expand terms and inspect context only inside the granted scope. Record gaps. Prior summaries may suggest questions but never substitute for primary historical evidence; without sources, use conversation evidence and explicitly unknown history.
2. Build a compact chronology: date/range, event/decision, reported or observed result, quote and epistemic status. Separate occurrence from recording time. Include changed environment, relationships and constraints when relevant.
3. Seek analogues and counterexamples. Explain similarities and differences. Pausing under family illness is not equivalent to abandoning a boring project.
4. Separate visible patterns from causes. State alternative explanations and what would refute each important interpretation. Report value changes without imposing a timeless identity.
   Trace Before → Trigger → Change with unknown nodes intact. Distinguish historical knowledge, attempted experience and reliably demonstrated skill. For possible Regression, preserve when the ability was available and the conditions in which it later failed; one failure does not erase past competence. Compare past Channels and their endings only when there is actual history.
5. Return sourced findings and unknowns. Say **Insufficient historical evidence** when no adequate analogue exists. Append a Pattern only when useful and supported, with a falsification question.

Output: chronology, analogues/differences, counter-evidence, optionally a provisional Pattern. Never disguise inferred historical Events as user testimony; cite existing notes in a Pattern instead.
