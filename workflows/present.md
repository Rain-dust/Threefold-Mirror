# Present · Current Human State Model

1. Read `model --at` and recent originals. Investigate decayed, expired, corrected or stale-source fields. No evidence for today means unknown, not automatically unchanged.
2. Choose dimensions useful to this question. Prefer language/categories; numbers require reported/observed quantities and units. Preserve conflicting reports as uncertainty.
3. Draft each claim with direct evidence, counter-evidence, source period, epistemic status, confidence, trend, scale, review and expiry. Two weeks of shorter sleep is short_term, not a stable personality claim.
   Keep Knowledge / Experience / Skill distinct. Describe transitions and Channels as current, bounded states; record Regression as conditional loss of access to a previously supported ability. Verify consequential self-reports while leaving unresolved ones as testimony. Connect domains and a possible core tension only with evidence, alternatives and time boundaries, never as a universal identity explanation. Use the [interview method](../INTERVIEW_MODEL.md) for gaps.
4. Compare with existing chains. Append a justified State revision explicitly superseding the prior head. No change needs no duplicate. Strengthen/weaken with evidence, not repeated AI summaries.
5. Read the projection again. Explain what changed, what remains unknown, corrections and review dates.

The script handles lifecycle; the Agent interprets evidence. If interrupted between independent dimensions, inspect what persisted, retry identical IDs/content for completed records, and finish only warranted missing revisions.
