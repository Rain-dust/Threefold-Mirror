# Reflection, correction and resumption

## Outcome → Reflection → model

Read the original Simulation. Compare the selected branch and matching horizon with actual Outcome. Unchosen branches are unobserved counterfactuals, not predictive successes/failures.

Use actual statements to record whether seeing the simulation changed behavior: influenced_by_simulation is yes/no/unknown, linked to intervention Events. Preserve alternatives. A projected failure not occurring may reflect intervention; without an appropriate comparison, do not infer accuracy, calibration or causal intervention value.

Append Reflection with Outcome citation, comparison, sourced lessons, confidence, alternatives and proposed updates. Then justify new State/Pattern revisions from **actual Outcome/original notes**, never from Reflection alone. If no update is supported, leave the model unchanged and explain why.

## User correction

1. Resolve the wrong State/Pattern/Prior Self Knowledge and read the user's statement plus original context. Clarify the target only if ambiguous.
2. Append Correction with actual user words and reason. The target (and claims depending on a corrected prior) immediately leaves the current model, even if later work is interrupted.
3. If supported, append corrected revision with supersedes and correction links. Confidence may become unknown. User disagreement does not automatically establish a new causal explanation.
4. Review materially dependent advice. Old simulations stay historical; explain if the correction changes an open decision and generate a fresh simulation if warranted.
5. Show the new model and retained history. Changing a value or time scope is valid; the user need not accept the previous interpretation.

## Interrupted work

Records are independent durable commits. Retry completed writes with identical IDs/content. Resume after persisted Outcome, Correction or partial State updates. Busy/interrupted locks fail clearly; verify no writer remains before removing the empty lock directory. Never erase completed records to restart a workflow.
